# Existing coverage

Resolve the case project through [project context](project-context.md).
Search titles, descriptions, conditions, and steps of current cases, including drafts.
Use two independent queries with different terms.
Read relevant candidates in full, including shared conditions.

Compare the initial state, actions, result, and variants.
Prefer an unchanged case, then an update. Explain why a new path needs a separate case.
For an editorial change, full reading of the target case is sufficient.

Record the scope, queries, candidate references, comparisons, and search limits.
Examine pagination and access before you conclude that no matching case exists.
Report incomplete searches as unavailable. Do not claim that no matching case exists.
Use an accessible fallback client or export when possible. Keep large case collections outside the agent context.
Skip the search only when the user states that no case database exists.

Stop when the decision has sufficient evidence. Read the target again before a change.
Repeat the comparison if its content changed.
